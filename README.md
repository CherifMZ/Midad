# مِداد — Midad

> **مدادٌ لما لا يُقال**

> *Ink for what cannot be said*

---

**Midad**, which means **ink**, is a small personal collection of words that deserve to remain somewhere.

A place for quotations, poems, fragments, and thoughts. Some are mine. Others belong to writers, poets, and thinkers whose words remained.

---

## Organisation

The home page is a doorway to three separate sections. Each section has its own page and can be opened directly:

### شَذَرَات — Shadharat

**Fragments**

Short pieces of writing gathered without the need for a single thread: a line from a poem, a sentence from a book, a quotation, or a thought worth keeping. Open [shadharat.html](./shadharat.html).

### هَامِش — Hamish

**The margin**

The place beside the text where a reader leaves something behind. Notes on [hamish.html](./hamish.html) are stored only in the visitor's browser.

### بَوْح — Bawh

**Unburdening**

Writing that is closer to the self. Open [bawh.html](./bawh.html).

The section descriptions and site interface follow the selected language. Arabic mode uses Arabic copy; English translations appear after choosing English.

## Files

- [index.html](./index.html) is the section-selection home page.
- [site.js](./site.js) renders shared navigation and section content.
- [site.css](./site.css) contains the shared visual system.
- [pieces.js](./pieces.js) contains the writing and its section assignments.

---

## Purpose

Midad is a personal archive of language.

Not everything written here needs an explanation.
Not everything needs to be finished.
Some things are kept simply because they stayed.
